FastDir package repositories

Signed apt and dnf/zypper repositories for FastDir (currently @VERSION@, x86_64). Once added, FastDir updates with the rest of the system.

Debian, Ubuntu and derivatives

sudo curl -fsSLo /usr/share/keyrings/fastdir.gpg @BASE@/fastdir.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/fastdir.sources @BASE@/fastdir.sources
sudo apt update
sudo apt install fastdir

Fedora, RHEL, Alma, Rocky

sudo curl -fsSLo /etc/yum.repos.d/fastdir.repo @BASE@/fastdir.repo
sudo dnf install fastdir

openSUSE

sudo zypper addrepo @BASE@/fastdir.repo
sudo zypper install fastdir

Signing key: fastdir.asc. Other platforms and formats: install instructions.
